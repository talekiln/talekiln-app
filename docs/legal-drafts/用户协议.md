## 2. 服务内容

1. 本软件在你的电脑上运行，帮助你组织故事、分镜、画面、配音和视频导出。
2. 生成图像、视频、文字、语音需要调用**第三方模型服务**。你使用**自己申请的 API Key**，请求从你的电脑直接发往该服务商，费用由服务商向你收取，**不经过也不由我们代收**。我们不提供、不托管、不保证任何第三方模型的可用性、质量与价格。
3. 云端服务：账号与登录、设备管理、授权（许可证）、模型目录与公告、意见反馈、订阅与支付（支付渠道尚在接入，上线前以实际开通为准）。
4. 免费版与专业版的权益差异（当前代码默认值）：免费版 1 台设备、导出最高 720 高度、画面带水印；专业版 3 台设备、导出最高 2160 高度、无水印，另含批量、云同步、专业模型等功能项。具体以订阅页面为准，我们可通过新增套餐版本调整，已付款订单按下单时版本执行。【待定：“云同步”等功能项目前代码中是否真实存在，上线前须核对，不得虚假宣传。】
