## 1. 我们是谁，这份政策管什么

故事窑（Talekiln，以下简称“本软件”）是一款安装在你电脑上的桌面软件，帮助你把故事做成分镜、画面、配音和视频。本软件分两部分：

1. **本机部分**：项目、素材、任务队列、你的 API Key 等，主要保存在你自己的电脑上。
2. **云端部分**：账号、授权、设备、意见反馈、（可能的）使用统计、订单。云端由我们运营。

本政策说明这两部分各自处理哪些信息。AI 生成使用的是**你自己申请的第三方模型服务**（如阿里云百炼、火山方舟），那部分由对应服务商按其自己的政策处理，见第 5 节。

## 2. 保存在你电脑上的信息（我们的云端收不到）

| 信息 | 位置与方式 | 备注 |
|---|---|---|
| 项目、剧本、分镜、时间线、生成的图片/视频/音频 | 本机 SQLite 数据库和本机存储目录（配置项 `storage.local_path`） | 云端表结构里没有这些内容；删除方法见第 8 节 |
| 提示词、生成参数、AI 任务队列与结果地址 | 本机数据库 | 同上 |
| 你填写的第三方服务 API Key | 系统密钥存储（经系统加密），界面只显示末 4 位 | 不上传云端；诊断包会脱敏 |
| AI 花费统计与上限设置 | 本机数据库 | 不上传 |
| 首次引导进度、AI 标识（水印/元数据）设置 | 本机数据库 | 不上传 |
| 你同意本政策与用户协议的版本与时间 | 本机界面存储 | 只记录“版本号 + 时间”，不上传 |
| 设备标识（随机生成的指纹） | 本机数据库，登录云端时才会发给云端（见第 3 节） | |
| 登录凭据（刷新令牌）与许可证令牌 | 系统密钥存储 | 退出登录时删除 |
| 运行日志 | 本机日志文件 | 日志经脱敏；你主动导出诊断包时才会被读取 |

## 3. 我们的云端收集和保存的信息

下表逐项对应云端数据库结构（`packages/cloud/prisma/schema.prisma`）与接口。**只有你使用对应功能时才会产生。**

### 3.1 账号与登录（邀请码注册、登录时）

| 字段 | 来源 | 用途 |
|---|---|---|
| 邮箱 | 你填写 | 账号标识、登录、（开票时的收票邮箱另见 3.4） |
| 口令 | 你填写 | 只保存不可逆的哈希，不保存明文 |
| 账号角色、套餐类型、停用标记、创建时间 | 系统生成 | 权限与授权判断 |
| 邀请码及其使用记录（使用者账号、使用时间） | 你填写 / 系统 | 内测准入 |
| 刷新令牌（只保存哈希）、签发/过期/使用时间、所属设备 | 系统 | 保持登录、检测令牌被盗用 |

> 代码里**没有**手机号、短信验证码、微信登录（计划中的 P2-C，上线后本节需补充）。

### 3.2 设备（登录或注册设备时）

| 字段 | 来源 | 说明 |
|---|---|---|
| 设备指纹 | 软件首次登录时随机生成的 UUID（形如 `fp-…`） | 不是硬件序列号、不是 MAC 地址 |
| **设备名称** | **你的电脑“主机名 + 系统平台”**（如 `XXX-PC (win32)`，截断到 100 字符） | 主机名可能含有个人姓名，**待律师确认是否构成个人信息、是否改为可编辑/不上传** |
| 创建时间、最近使用时间、吊销时间 | 系统 | 设备数量上限管理 |

### 3.3 授权（许可证令牌）

每次签发许可证令牌，云端记录：账号、设备、套餐代码、签发时间、到期时间（表 `LicenceUsage`）。用于用量与审计。令牌本身存于你的电脑。

### 3.4 订阅、订单、发票（购买专业版时）

- **订阅**：账号对应的套餐版本、当前授权起止时间。
- **订单**：商户订单号、套餐版本、计费周期（月/年）、金额（分）、支付渠道、状态、支付二维码地址、创建/过期/付款时间、本单授权区间。
- **支付流水**：渠道、渠道交易号、金额、付款时间；**回调去重记录**：渠道、通知号、商户订单号、接收时间。
- **退款**：退款单号、金额、状态、原因、渠道退款号、失败原因、经办人（管理员账号 ID）、时间。
- **发票登记**（你申请开票时）：抬头、税号（可选）、收票邮箱、金额、状态、发票号。

我们**不保存**你的银行卡号、微信/支付宝账号密码；付款在支付渠道页面完成。*（真实支付渠道尚未接入，当前代码只有模拟实现；接入后本节需按实际渠道返回的字段复核。）*

### 3.5 意见反馈与诊断包（只有你点击“发送”才上传）

不会自动上传。你在反馈界面点击“发送”后，云端收到并保存：

| 内容 | 说明 |
|---|---|
| 问题描述（≤4000 字） | 云端会再做一次密钥类内容的遮盖，但**请不要在描述里写密码或 Key** |
| 联系方式（选填，≤200 字） | 你自愿填写 |
| 相关任务编号（选填）、软件版本 | |
| 安装标识（匿名随机 ID） | 代码支持随反馈上传，**当前版本的界面接线尚未传入**，是否传入【待定】 |
| 诊断包 zip（仅当你勾选“附带诊断包”，≤约 1.5MB） | 见下 |
| 提交时间 | 系统生成 |

反馈提交接口不要求登录，云端**不会**把反馈关联到账号（账号字段目前恒为空）。

诊断包的内容（本机生成并脱敏后才上传）：
- 软件与运行环境版本（Node/Electron/Chrome 版本）；
- 系统信息：平台、架构、系统版本号、CPU 核数、内存总量与空闲量、语言区域、时区。**不含**主机名、用户名、网卡/MAC、环境变量、完整路径；
- 最近 AI 任务的白名单字段（任务 ID、服务商、类型、状态、重试次数、错误码、时间、错误信息前 200 字），**不含**提示词、参数、结果地址；
- 本机日志文件末尾（每个文件最多 512KB），已遮盖：已知 Key、各类厂商 Key 与令牌格式、URL 中的签名/令牌、邮箱、用户目录与用户名、提示词/脚本/对话正文类字段。
- 脱敏是规则匹配，**不保证 100% 覆盖**，你可以先“导出诊断包”到本机，检查后再发送。

### 3.6 使用统计（匿名遥测）

- 云端**有**接收接口，允许的事件只有：应用打开、引导步骤、连通测试、项目创建、导出完成/失败、任务失败，字段只有事件名、错误码、步骤名、匿名安装标识（随机 UUID）、软件版本，以及服务器收到的时间。不含账号、IP（代码不记录）、提示词、路径、Key。
- 本机的统计客户端模块**默认关闭（需用户主动开启）**，但在 2026-10-01 的代码里**尚未接入应用，也没有“开启统计”的界面开关**，因此**当前版本不会发送任何统计**。
- 【待定】：正式版是否上线统计；若上线，必须先提供开关与说明，并相应更新本节。

### 3.7 推广链接点击

在“添加 Key 向导”里点击“去服务商获取 Key”时，如已配置云端，你的浏览器会先访问我们云端的跳转地址，再跳到服务商页面。云端记录：服务商代码、来源位置标签、点击时间。**不记录账号、IP、浏览器标识**（代码不写入）；跳转时设置了不发送来源页（no-referrer）。跳转目标只来自我们的配置。若我们通过推广链接获得服务商的返佣，会在界面上披露【待定：披露文案，待律师确认】。云端未配置时，直接打开服务商官方页面，不带推广参数，也不经过我们。

### 3.8 软件向云端发起的其他请求

登录/续期/刷新令牌/吊销设备；拉取公开的模型与价格目录和公告；拉取许可证验签公钥。这些请求本身不附带你的项目内容。

### 3.9 服务器层面的记录

应用代码不持久化你的 IP 地址（仅在内存中用 IP 做限流计数，重启即清）。但服务器、反向代理、云厂商可能留有访问日志，其内容与保留期限**【待定：部署方案确定后补充】**。

## 4. 我们不收集什么

我们的云端**不保存**你的项目、剧本、提示词、生成的图片/视频/音频；**不收集**通讯录、位置、麦克风/摄像头数据；**不读取**你电脑上的其他文件。

## 5. 你的内容会发给谁（第三方）

1. **你选择的模型服务商**。当你点击生成，软件在本机直接把提示词、参考图、剧本等发给你配置的服务商（当前开放：阿里云百炼；火山方舟代码已有、是否开放由配置决定），使用的是**你自己的 Key**，不经过我们的云端。服务商按其政策处理这些内容并计费；其输出内容的权属与责任见《用户协议》与《AI 生成内容与使用规范》。
2. **第三方图片中转服务（代码里存在，需处理）**：代码内置了一个第三方图床 `imageproxy.zhongzhuan.chat`，在“多图参考视频”路径下，本地参考图可能被上传到该图床以得到公网地址（配置 `image_proxy.use_for_video` 当前为 `true`）。这与此前审计文档“一期默认关闭”的结论不一致，见《待决问题与代码缺口》。**在核实并决定保留、关闭或改为征得同意之前，本节不得对外发布。**
3. **支付渠道**（微信支付、支付宝）：接入后用于收款与退款，【待定：渠道名称与其处理者地位，待律师确认】。
4. **云服务/托管服务提供者**：用于运行我们的云端，【待定：名称、所在地】。
5. **软件更新服务**：桌面端自动更新会向配置的更新地址请求新版本信息，该地址上线前【待定】。

## 10. 安全措施

口令只存哈希；令牌使用签名和过期机制，刷新令牌轮换且重放会吊销整个家族；Key 存系统密钥存储；诊断包上传前脱敏并有大小上限；云端接口有限流。没有任何系统是绝对安全的，发生个人信息安全事件时的通知流程【待定】。

## 11. 本政策的变更

变更会更新版本号；软件在首次引导时记录你同意的版本与时间，版本升级后需要重新确认。**目前代码只在首次引导时询问**，已有用户在版本升级后的再次确认流程尚未实现，见《待决问题与代码缺口》。
