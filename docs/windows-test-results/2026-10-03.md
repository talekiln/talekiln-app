## 只能用真 Key 或真环境验证的部分

下列内容到目前为止只用假服务商或源码级测试验证过，没有在界面里用真 Key 跑过：

- 出图 / 出视频 / 配音经队列生成的整条路径。
- 百炼草稿档：只有「不带参考图的出图」会换 `z-image-turbo`，其价目是占位价（`verified:false`）；草稿视频没有节省。
- 方舟草稿档（只加 `--rs 480p`）与方舟多参考图的通用片段模式。
- 资产（角色 / 场景 / 道具）出图：走旧同步路由，需要把 `generation.legacy_enabled` 设为 `true`，默认配置下按钮禁用。
- AI 写剧本的成功路径（需要配置文本模型）。
- 导出成片与烧录：需要渲染核心，未连接时是 `503 CORE_UNAVAILABLE`。
- 团队库 `add-to-team-library`：需要工作室服务，否则 `501`。

汇总的已知缺口见 `docs/phase3-plan.md` 的「四视图统一工作台」一节。
