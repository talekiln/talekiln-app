# AI 生成内容标识（G04）

本文说明导出视频时已实现的标识能力，以及**必须由法务/合规确认**的部分。以下内容是工程侧对相关规定的理解，**不构成合规结论**。

涉及的规定（写代码时参考的版本，使用前请核对现行有效文本）：

- 《人工智能生成合成内容标识办法》（国家网信办等四部门，2025 年 9 月 1 日起施行）
- 强制性国家标准 GB 45438-2025《网络安全技术 人工智能生成合成内容标识方法》

## 已实现

### 设置

- 全局设置 `aigc.settings`（存在 `global_settings` 表），接口 `GET/PUT /api/v1/settings/aigc`。
- 字段：`watermark`（显式水印，默认开）、`metadata`（隐式元数据，默认开）、`producer`（内容制作方名称，默认 `Talekiln`）。
- 导出页提供开关；关闭任一项时界面会提示需自行承担合规责任。

### 显式标识（画面水印）

- 文字固定为 `AI生成`。
- 导出时在**发给 render.start 的时间线副本**里追加字幕片段，由现有的字幕烧录管线（libass）画到画面上；数据库里保存的时间线不会被修改。
- 位置在画面顶部居中。前 3 秒字号为画面短边的 5.5%（粗体、白字黑边），之后到片尾持续显示，字号为短边的 3%。
- 不需要修改 `packages/core`（Rust）。水印属于字幕内容，因此会进入场景缓存键：开关变化后会重新渲染受影响的场景，不会误用旧缓存。
- 中文字体默认写 `Microsoft YaHei`；Linux 或缺字体的机器上由 fontconfig 回退。已在 Linux（WenQuanYi 字体）上用真实 ffmpeg 渲染验证过画面效果，Windows 真机未验证。

### 隐式标识（文件元数据）

- 渲染完成后，用 ffmpeg 对输出文件做一次**流拷贝重封装**（`-c copy`，不重新编码），写入：
  - `AIGC` = `{"Label":"1","ContentProducer":"<制作方>","ProduceID":"<本次导出的 UUID>"}`
  - `comment` = `AI生成（人工智能生成合成内容）· <制作方>`
  - 使用 `-movflags +faststart+use_metadata_tags` 让 MP4 保留自定义键名。
- 先写临时文件再改名；写入失败时导出任务状态为 `failed`，并**删除**已渲染但未带标识的文件，避免未标识的文件被误用。
- 该步骤在 JS 侧完成（`packages/local/src/export/aigc.js`），因为 `render.start` 目前没有 metadata 参数。若希望一步完成，可以给 Rust 的 `final_args` 增加 `-metadata` 参数；这是单独的小改动，本次未做。
- 已用真实 ffmpeg/ffprobe 验证：标签可被 ffprobe 读出，音视频流保持不变。

## 必须由法务确认（未确认前不要对外声称合规）

1. **元数据字段与格式**：`AIGC` 这个键名、字段集合（`Label`、`ContentProducer`、`ProduceID`，以及标准中的 `ContentPropagator`、`PropagateID`、`ReserveCode1/2`）、`Label` 取值含义（当前写 `1`，按"确认为生成合成内容"理解）、JSON 是否需要转义或编码，必须对照 GB 45438-2025 现行文本逐项核对。MP4 容器里应写在哪一层（`udta`、`meta`/`ilst` 或扩展字段）标准是否有硬性要求，也需确认；ffmpeg 的 `use_metadata_tags` 写入位置是否被认可，待确认。
2. **显式标识的位置、大小、时长**：视频应在片头、片中、片尾哪些位置标识，文字大小下限（当前按短边 5.5%/3% 取值，是参考记忆中的比例，**数值未经核对**），片头标识最短时长（当前 3 秒），是否允许仅片头加持续角标，是否需要在播放页或交互界面另行提示。
3. **`ContentProducer` / `ProduceID` 的取值**：制作方应填企业全称还是统一社会信用代码或平台编码；`ProduceID` 的生成规则、是否需留存对应记录。
4. **谁承担标识义务**：本软件作为本地工具，导出文件由用户发布。服务提供者、传播平台、用户各自的义务边界，以及用户关闭水印或元数据时（办法允许的特定场景及留存日志要求）应有哪些提示和记录，需要确认。当前仅在界面上给出提示，不做日志留存。
5. **云端模型的标识**：百炼、方舟等服务商生成的素材可能已带其自身的显式/隐式标识。二次剪辑后是否需要保留、叠加或改写原标识，需确认；当前实现只追加我们自己的标识，不读取也不保留素材原有元数据（重新编码会丢失）。
6. **其他格式**：目前只导出 MP4。图片、音频单独导出时的标识未实现。
7. **平台差异**：抖音、快手、视频号等平台各自有声明或检测规则，导出文件是否满足，需要逐个平台确认。
