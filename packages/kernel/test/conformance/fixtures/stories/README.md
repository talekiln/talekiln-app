# 一致性套件的样例故事

共 13 个，全部是**确定性静态文件**，套件里每个场景都在每个故事上跑一遍。

## 真实 AI 输出（10 个，复用）

`gf-01..04`（国风短剧）、`ps-01..03`（产品种草）、`ke-01..03`（知识科普）是 D02 分镜生成（scriptgen）联网会话里
用 qwen-plus 跑出来的 10 个**真实输出**，原件在
`packages/local/test/fixtures/scriptgen/recorded/<id>.json`（commit 22eb85d 引入），故事原文在同目录 `samples.json`。
这里只做了两件事：取最后一次尝试并解析成 JSON（`storyboard` 字段），附上故事原文和来源；内容一字未改。
它们是分镜表（镜头 + 台词），不是剧本；`../../stories.js` 用一个固定规则把它们转成内核的“场景 / 行 / 镜头”：

- 场景名 -> 场景组 + 一行 `scene_heading`（挂到该场景第一个镜头）；
- 每个镜头的 dialogue -> 一行 `narration`（speaker=narrator）或 `dialogue`（speaker=角色名），挂到该镜头；
- 镜头的 visual -> 一行 `action`，每个无台词的镜头必有，其余每 3 个镜头取 1 个；
- 同一场景的镜头保持原相对顺序（ps-01 的原始镜头在 s1,s3,s2 间交错，按场景归组后顺序改变，这是转换的结果，不是内核行为）。

## 手写边界故事（3 个，**手写，非 AI 输出**）

用来覆盖真实输出里没有的形状，直接用内核“场景 + 行 + 镜头”形式书写：

- `edge-single`：一个场景、一个镜头、一行；
- `edge-multiline`：一镜多行、有不挂任何镜头的行、有没有镜头的空场景、很长的独白、1 秒短镜头；
- `edge-narration`：纯旁白、三场景各三镜头、没有对白。
